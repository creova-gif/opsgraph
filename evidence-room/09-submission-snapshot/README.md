## 1. Pre-Submission Gate Checklist

Before hitting "Submit Application" on the YC portal:

- [ ] **Deadline & Batch:** Current YC deadline and batch details re-checked on [ycombinator.com/apply](https://www.ycombinator.com/apply).
- [ ] **One-Liner Test:** One-line description passes the *"stranger understands it in 10 seconds"* test without buzzwords.
- [ ] **Customer Numbers Reconciled:** All user, customer, and revenue counts reconciled against `02-metrics/weekly-tracker.md` as of submission date.
- [ ] **Clear Distinctions:** Free/unpaid pilots, paying customers, and waitlist leads are distinguished with absolute transparency.
- [ ] **Working Demo:** Demo link works without specialized login credentials, or includes a clear test account with narrow scopes.
- [ ] **Founder Video:** 1-minute video follows instructions: direct speech, no music, no pitch slides, plain founder presence.
- [ ] **Competitors Named:** Incumbents (Vanta, Notion, Fractional COOs) named explicitly with distinct boundaries.
- [ ] **No Unsupported Claims:** No fake TAM precision; zero claims that AI guarantees legal or audit compliance.
- [ ] **Adjective Purge:** Unnecessary adjectives ("game-changing", "revolutionary", "all-in-one") purged from all written responses.
- [ ] **Local Archive:** A markdown copy of the exact submitted text is archived in this directory (`final-submitted-application.md`).
